# OpenCapt 文档索引

English: [en/README.md](en/README.md)

这组文档面向两类人：

- 想快速理解 OpenCapt 架构和主要模块的读者
- 想参与开发、修 bug、扩展 provider 的贡献者

推荐阅读顺序：

1. [architecture.md](architecture.md)  
   先理解程序运行时是怎么组织起来的。
2. [code-map.md](code-map.md)  
   再看代码入口和模块职责，从哪里开始读。
3. [capture-overlay-flow.md](capture-overlay-flow.md)  
   重点理解截图、框选、标注、输出和贴图主链路。
4. [ocr-translation.md](ocr-translation.md)  
   理解 OCR / 翻译 provider 结构和结果如何回到 overlay。
5. [development.md](development.md)  
   最后看开发、调试、打包和常见坑。
