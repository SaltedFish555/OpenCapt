# OpenCapt Documentation

中文：[../README.md](../README.md)

These documents are for two audiences:

- readers who want to understand how OpenCapt is structured
- contributors who want to debug, extend, or maintain the project

Recommended reading order:

1. [architecture.md](architecture.md)  
   Understand the runtime shape first.
2. [code-map.md](code-map.md)  
   Learn where to start reading the code and what each subsystem owns.
3. [capture-overlay-flow.md](capture-overlay-flow.md)  
   Follow the main capture, selection, annotation, export, and pin flow.
4. [ocr-translation.md](ocr-translation.md)  
   Understand provider layering and how OCR / translation results return to the overlay.
5. [development.md](development.md)  
   Use this for day-to-day development, debugging, and packaging.
